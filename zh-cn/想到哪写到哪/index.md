# 想到哪写到哪（一）




<!--more-->

运动完路过公司楼下，口渴想上来喝杯水。

最近我把自己的电脑也放到这了，周末来写写论文，因为出租屋漏风太冷，只适合呆在被窝里。在工作的环境里学习效率也高一些，只可惜我发现得太晚了，距离离开这里还有不到两个月的时间。我还是挺喜欢这里的，在它还没有压榨我之前，事少、钱多、离家近、大哥不PUSH，符合初入职场的我对于完美实习工作的所有幻想。白驹过隙，已经过去516天了，时间快到令我恐惧，我仿佛能一眼看到我人生结束的那一天。听说人对时间的感知是根据新鲜感来决定的，对时间的感知就是时间带给人的体验，当你经历新鲜事物的时候，相同的时间能给你更多更丰富的反馈，大脑处理这些事物时就觉得时间“慢”了。这种说法是有道理的，我也尝试过一些新鲜的事物来丰富对生命的体验。但坦白讲，**我不喜欢新鲜感**，它干扰我对于一个事物的真实评价，让我兴奋，让我混乱。在涉及事物评价的时候，我需要更多的时间来消耗这种新鲜感，让我认清自己内心究竟是怎么想的。当然新鲜感也有益处，它是我好奇心的奖励，尤其是在哪些新鲜感很难枯竭的地方（比如学习）。体验归体验，评价归评价，我批判地享受着它。

最近还感觉到，**人好像都是傀儡**。起因是我偶然发现自己很多自以为独特的观点，似乎并不是自己的，而是在之前人生的某个经历中获得的（可见人想要“独特”有多么困难）。可能因为初高中的我喜欢看一些富有哲理的故事和名言，想以此来弥补自己浅薄的人生经历，期望它们能指导自己的未来。当然这是荒谬的，道理是悟来的，不是学来的。这世界上从来没有真正的感同身受，当试图理解一个观点时脑海里没有对应的人生体验，那便读不懂它真正的含义。在绝大部分人身上也能看见傀儡的影子，世界似乎被少数能人所主导，多数人不自知地成为了他们的传道者，或多或少地对接受到的东西进行加工，获得了“自己”的东西。想想也合理，人类有灵智以来已经经历了足够久的岁月，无数的人和悠长的历史形成的“面板数据”已经将人生的角角落落都探索了个遍，更何况其中不乏心思敏锐感悟生活的人，即便流传下来的比例很小，也没有什么新东西了。

人真容易受到环境和他人的影响。这是人作为群体动物进化而来的生存法则，无可厚非。只是感觉这样的自己好像失去了自我，没有了成为自己的必要。我为什么是我？为什么意识不能脱离束缚在肉体中穿梭？为什么此时此刻我会坐在这里？...... 哦，我碰巧是我。意识的诞生荒诞可笑，随机钉下的钉子禁锢着我的一生。生是偶然，死是必然，我只能是我。这样的想法可能看上去比较消极，但实际上我并不是一个消极的人。**人应该进步**，这是我最基本的生活态度，也是反驳消极评价的最好证据。我不过是反复思考关于人的哲学问题，哲学三问总结得很好：“我是谁？”，“我从哪里来？”和“我要到哪里去？”，哲学上的事气氛很难欢快。

思考是意识跟意识对话，运动是意识和肉体对话，学习是意识和知识对话，这应该就是我善于独处的原因。反观近年来的独处时间，我可能会觉得无聊，但几乎没感觉到过孤独。毕竟每个人从出生开始就是绝对独立的个体，不必需任何人来活，我只不过是回归到了生命最初始的状态。在单核CPU下，思考太多挤占了另一个进程获得的时间片——感受。意识激烈斗争时我屏蔽的物理世界带来的风吹草动，让我变得麻木。而且，上大学以来的各种课程学习和学术训练也让我的文字变得呆板，或者说得好听点，力求严谨，不露破绽。近两年才感觉到，文字的作用从来都不是推理和证明，这是数学符号的任务。文字独特且擅长的描述感受，传达感情。**能引起人共鸣的文字就是好文字**。充分地感受再细腻地传达出来，距离这点我还有很长的路要走。
